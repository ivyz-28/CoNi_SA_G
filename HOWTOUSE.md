# How to Use:
Download files and setup dependencies as per [README.md](https://github.com/ivyz-28/CoNi_SA_G/new/main#:~:text=Version%201-,README,-.md)

## Structure_predictor.py:
Ensure '[CoNi.cif](https://github.com/ivyz-28/CoNi_SA_G/new/main#:~:text=Version%201-,CoNi,-.cif)' file is downloaded and in the same directory as [Structure_predictor.py](https://github.com/ivyz-28/CoNi_SA_G/new/main#:~:text=Statistical_analysis.py-,Structure_predictor,-.py)
Within file, change ```single_atom``` variable to desired single atom element symbol
```
single_atom = None # Change to desired single atom symbol
```
Change from cpu to cuda if able to access gpu
```
predictor = pretrained_mlip.get_predict_unit("uma-s-1p2", device="cpu") # Change device to "cuda" if using gpu
```
Upon running code, relaxation will occur automatically and results will all be saved into new sub-directory 

## Statistical_analysis.py:
Ensure '[Single Atom Energies.xlsx](https://github.com/ivyz-28/CoNi_SA_G/new/main#:~:text=CoNi.cif-,Single,-Atom%20Energies.xlsx)' is downloaded and in the same directory as [Statistical_analysis.py](https://github.com/ivyz-28/CoNi_SA_G/new/main#:~:text=Atom%20Energies.xlsx-,Statistical_analysis,-.py)
Within file, change ```metals``` list to include all desired single atoms and ```out_direc``` to specify output directory
```
metals = [] # Change to include all desired single atoms
out_direc = "." # Change to desired output directory
```
Upon running code, statistical graphs will all be saved into desired output directory as .pdf and .png layout

## Interpreting Graphs
- Graphs are displayed as a histogram of adsorption energy of hydrogen range plotted against existence probability
- Black line is a fitted Gaussian Mixture Model generated by scikit-learn to show what rough distribution looks like
- Red bars indicate probability of structures within desired adsorption energy range of -0.35 to -0.05 eV
- Mean adsorption energy plotted as vertical line and labelled in legend, as well as probability of GMM curve within -0.35 to -0.05 eV
- Desired adsorption energy at SLC is -0.20eV (corresponding to Gibb's Free Energy of Hydrogen value of 0.00eV)
